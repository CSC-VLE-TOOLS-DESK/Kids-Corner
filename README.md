# Kids Corner

Free picture games for KG, UKG and Class 1 in English and Hindi (38 games). Static site for GitHub Pages.

- Live: https://csc-vle-tools-desk.github.io/Kids-Corner/
- Part of SevaSphere: https://csc-vle-tools-desk.github.io/SewaSphere/
- Open `index.html` to play. `offline/Kids_Corner_offline.html` is a single file that works without internet (for school demos).
- Change a picture: replace the PNG in `assets/kids/` with the same name (about 400x400).
- Future lessons: add under `lessons/`.

Version: Kids Corner repo v1 (moved out of SevaSphere v4_12).
